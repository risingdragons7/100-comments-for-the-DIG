# SenseiBulrog Raw Tetra Hydrinium Farm Comments

A simple static page with 100 ready-to-use chat comments for SenseiBulrog's stream (Faded Monsuta / Raw Tetra Hydrinium / !dig farming).

Each comment has its own **Copy** button. There's also a **Copy All** button.

## How to host on GitHub Pages

1. Create a new public repository on GitHub (e.g. `senseibulrog-comments`)
2. Upload the `index.html` file into the repository
3. Go to **Settings → Pages**
4. Under "Source", select **Deploy from a branch**
5. Choose `main` (or `master`) and `/ (root)`, then Save
6. After a minute or two your site will be live at:  
   `https://YOUR-USERNAME.github.io/senseibulrog-comments/`

That's it — pure static HTML, no build step needed.
